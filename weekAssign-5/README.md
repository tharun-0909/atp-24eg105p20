# Week 5 Assignments

This repository contains the assignments and projects for Week 5, covering advanced HTML/CSS concepts, Tailwind CSS, and introductory React applications.

## Directory Structure

### Day-12
Contains HTML and CSS assignments focusing on:
- `Assignment-1`: HTML Tables and styling (`tables.html`, `style.css`)
- `Assignment-2`: HTML/CSS layouts and styling (`index.html`, `style.css`)

### Day-13
Contains further HTML and CSS assignments:
- `Assignment-1`: Webpage layout and design (`index.html`, `style.css`)
- `Assignment-2`: Design implementation including images/logos (`index.html`, `style.css`, `logo.png`)
- `Assignment-3`: Webpage creation with illustrations and CSS styling (`index.html`, `style.css`, `city_logo.png`, `food_illustration.png`)

### reactAssign
Contains React-based assignments and Tailwind CSS integration:
- `Tailwind`: Assignment demonstrating Tailwind CSS configuration and usage.
- `react-app-1`: A React application bootstrapped with Vite, covering fundamental React concepts.
- `react-app-2`: Another React application bootstrapped with Vite.

## Technologies Used
- HTML5
- CSS3
- Tailwind CSS
- React.js (with Vite)
- Node.js & npm

## How to Run React Apps

For the React applications (`react-app-1` and `react-app-2`), navigate to the respective directory and execute the following commands:

```bash
# Install dependencies
npm install

# Start the development server
npm run dev
```

Open the provided local server URL (usually `http://localhost:5173`) in your browser to view the application.
