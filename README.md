# Week-4 Assignment: Basic HTML & CSS

This repository contains the Week-4 assignments, focusing on the fundamentals of web development using HTML and CSS. The assignments demonstrate structural tagging, content organization, and basic visual styling.

## 📁 Project Structure

```
weekAssign-4/
└── Week-4/
    ├── Assignment1(first program).html
    ├── Assignment2(pochi).html
    └── style.css
```

## 📝 Assignments Overview

### 1. Assignment 1: First Webpage
- **File:** `Assignment1(first program).html`
- **Objective:** Master basic HTML text formatting and list structures.
- **Key Features:**
  - Semantic use of `<h1>` for main titles.
  - Paragraph organization with `<b>` (bold) and `<i>` (italic) tags.
  - Hyperlink integration to external sites.
  - Multi-level nested lists to organize categories (Fruits, Vegetables, Cereals, Nuts).

### 2. Assignment 2: Pochi the Cat Profile
- **File:** `Assignment2(pochi).html`
- **Objective:** Create a structured profile page using combined HTML and external CSS.
- **Key Features:**
  - Image integration with float alignment.
  - Ordered lists for profile details.
  - Unordered lists for external links.
  - Implementation of a horizontal rule (`<hr>`) and footer class.
  - External stylesheet linking for consistent design.

### 3. Styling
- **File:** `style.css`
- **Description:** Provides the visual layer for the Pochi the Cat profile.
- **Styles Included:**
  - Custom font family (Georgia, serif).
  - Background coloring and margin adjustments.
  - Specific border styling (green left border for the body).
  - Image layout (right-aligned with padding and borders).
  - Typography enhancements for headings and paragraphs.

## 🚀 How to Run
Simply open any of the `.html` files in your preferred web browser (Chrome, Firefox, Edge, etc.) to view the rendered pages.
