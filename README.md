# Week-4 Assignment: Mastering Web Development Basics

## 🚀 Overview
This repository contains the comprehensive assignments for Week 4, covering HTML, CSS, and advanced JavaScript concepts such as Asynchronous programming, Promises, and Array Methods.

## 📂 Project Structure

### 🌐 HTML & CSS Assignments (`/Week-4`)
- **Assignment 1 (First Program)**: Structural HTML tagging, heading hierarchy, and nested lists.
- **Assignment 2 (Pochi the Cat)**: A complete profile page featuring image integration, list formatting, and external styling.
- **Styling (`style.css`)**: Professional Georgia-based typography, right-aligned image layouts, and custom borders.

### 📜 JavaScript Core Concepts (Root)
- **`arraymethods.js`**: Demonstrates the power of `filter`, `map`, `reduce`, `find`, and `findIndex` on a mock e-commerce cart.
- **`promises.js`**: A deep dive into the Promise lifecycle (Pending, Resolved, Rejected) using a marks evaluation scenario.
- **`asynchronous.js`**: Implementation of `setInterval` and `setTimeout` for handling OTP timeouts and periodic tasks.
- **`spread.js` & `shallowcopy.js`**: Exploration of modern ES6+ object and array manipulation.

### 🛠️ Day 3 Logic (`/day3ass.js`)
- **`validator.js`**: Robust form validation logic.
- **`arrayfunctions.js`**: Specialized utility functions for array data processing.
- **`task.js`**: Implementation of task-based logic.

## 💻 Tech Stack
- **Languages**: HTML5, CSS3, JavaScript (ES6+).
- **Concepts**: DOM Structure, Box Model, Async/Await patterns, Functional Programming.

## 🔧 How to Use
1. **Web Pages**: Open any `.html` file in the `Week-4` directory using a browser.
2. **JavaScript Logic**: Run the `.js` files using Node.js:
   ```bash
   node promises.js
   ```
