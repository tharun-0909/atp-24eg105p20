# Week 4 Web Development Assignments

This repository contains the HTML and CSS assignments for Week 4. It focuses on foundational web development concepts including HTML document structure, text formatting, lists, images, links, and basic CSS styling.

## Project Structure

The assignment is divided into two main parts:

### 1. Assignment 1 (First Program)
**File:** `Assignment1(first program).html`

A foundational HTML page designed to demonstrate basic HTML tags and content structure.
- **Concepts Covered:**
  - Standard HTML5 boilerplate (`<!DOCTYPE html>`, `<html>`, `<head>`, `<body>`).
  - Text formatting with headings (`<h1>`) and paragraphs (`<p>`).
  - Inline text styling (bold `<b>`, italic `<i>`).
  - Hyperlinks (`<a>`).
  - Lists: Unordered lists (`<ul>`, `<li>`) and nested lists to create hierarchical bullet points (e.g., categorizing fruits and vegetables).

### 2. Assignment 2 (Pochi)
**Files:** `Assignment2(pochi).html`, `style.css`

A simple profile page for a fictional cat named Pochi, showcasing the integration of HTML with an external CSS stylesheet.
- **HTML Concepts Covered:**
  - Structural headings (`<h1>`, `<h2>`).
  - Displaying media using the image tag (`<img>`).
  - Ordered lists (`<ol>`) for structured data.
  - Hyperlinks and horizontal rules (`<hr>`).
- **CSS Concepts Covered (`style.css`):**
  - External stylesheet linking via the `<link>` tag.
  - Typography styling (font families, sizes, weights, colors, line heights).
  - Box model properties (margins, padding, borders).
  - Floating elements (`float: right;`) to position images alongside text.
  - Basic CSS classes (e.g., `.footer`).

## How to View

To view the assignments, simply open the HTML files directly in any modern web browser (e.g., Chrome, Firefox, Safari, Edge).
- Double-click on `Assignment1(first program).html` to see the first exercise.
- Double-click on `Assignment2(pochi).html` to see the styled profile page. The browser will automatically load the accompanying `style.css` file.
